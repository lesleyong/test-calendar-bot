# Claude Instructions

## PRD Maintenance

**Always update PRD.md when making any changes to features, commands, data model, or behaviour.** This includes:
- Adding, removing, or modifying commands or their arguments
- Changes to the data model (schema, field names, types)
- Changes to bot output format
- Changes to scheduler or reminder logic
- Any new non-goals or rules

Keep the PRD as the single source of truth for what the bot does.
